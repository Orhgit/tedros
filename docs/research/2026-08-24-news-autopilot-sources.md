# מקורות חדשות לאוטופיילוט יומי (TED-114)

**תאריך:** 2026-08-24
**מטרה:** לזהות מקורות חינמיים, חיים וזמינים לסריקה אוטומטית יומית, להזנת קרון החדשות באתר Tedros (`app/lib/news/articles*.server.ts`).
**סטטוס נוכחי:** כל התוכן היום סטטי/ידני. אין מנגנון סריקה.

כל הבדיקות בוצעו בפועל (curl/WebFetch) ב-2026-08-24, לא רק על סמך תיעוד. מסומן `[נבדק ✓]` מול `[דורש אימות חוזר]`.

---

## Executive Summary

- **הממצא המרכזי:** ל-gov.il (כולל משרד הבינוי והשיכון, משרד העלייה והקליטה) יש הגנת **Cloudflare** שחוסמת בקשות curl/WebFetch רגילות (403), גם עם User-Agent של דפדפן. סריקה ישירה של דפי gov.il לא אמינה ל-cron יומי בלי headless browser + פתרון אנטי-בוט — לא ROI חיובי ל-MVP.
- **התגלית הכי שימושית בפועל:** `data.gov.il` (CKAN) — הפורטל **הנפרד** מ-gov.il הראשי, **לא חסום**, עם API JSON תקין. מצאתי דאטהסט חי ומתעדכן של משרד הבינוי והשיכון: **הגרלות "מחיר למשתכן" / "דירה בהנחה"** — 2,352 רשומות, resource אחד עודכן ב-16.8.2026 (כלומר בפועל מתעדכן, לא סטטי). זה בדיוק הזוית "משכנתא קהילתית / מכרזי דיור" שהמשימה ביקשה, ובפורמט JSON נוח לפרסינג — לא צריך scraping של HTML בכלל.
- **רמ"י (רשות מקרקעי ישראל)** — יש להם ארגון ב-data.gov.il אבל רק 3 דאטהסטים, ואף אחד לא מכרזים חיים. הדאטהסט הכי קרוב (מלאי תכנוני למגורים) לא עודכן מ-2022. **אין API/RSS אמיתי למכרזי רמ"י** — כל "עדכונים אוטומטיים" שמצאתי הם שירותי צד ג' בתשלום (rmiclick.co.il) שכנראה עצמם עושים scraping/מיילים.
- **עיריות (לוד, נתניה, אשדוד, קריית גת, ב"ש, ראשל"צ):** בדקתי חיבור בפועל — lod.muni.il מחזיר היום 302 להפניה ל-`abuse.spd.co.il` (עמוד "abuse" של ספק דומיינים) — כלומר **האתר כרגע לא פעיל/מושעה** (ייתכן זמני, כדאי לבדוק שוב לפני שבונים תלות). שאר העיריות (נתניה, אשדוד, ב"ש, ראשל"צ) עולות (200/302 רגיל) אבל **לא מצאתי RSS feed בפועל** באף אחת — רק CMS גנרי בלי autodiscovery. קריית גת (`k-gat.muni.il`) לא ענתה בכלל (timeout/DNS).
- **וואלה (Walla)** — יש RSS אמיתי ועובד: `https://rss.walla.co.il/feed/1` (חדשות כלליות, 200 OK בפועל), `feed/2` (כלכלה), ויש עשרות feed IDs נוספים (נדל"ן, מקומי) שמופיעים בעמוד המקורות אך **לא אימתתי כל ID בנפרד** — רק 3 מתוך הרשימה. אין feed ייעודי ל"יוצאי אתיופיה"/"עלייה" — יהיה צריך פילטור טקסט אחרי המשיכה.
- **Google News RSS** — עובד מצוין, בדיקה בפועל על שאילתה "יוצאי אתיופיה דיור" החזירה feed תקין עם 50+ כתבות רלוונטיות (Globes, TheMarker, Calcalist, ice, אתר עיריית נתניה) משנים שונות. זה הפתרון הכי גמיש וזול לכיסוי "עיתונות + חדשות קהילתיות" בלי לתחזק אינטגרציה לכל אתר בנפרד.

## Findings לפי מקור

### 1. gov.il / רמ"י — API/RSS למכרזי דיור

| בדיקה | תוצאה |
|---|---|
| `gov.il/.../RSS` (עמוד RSS כללי, קיים לכל משרד לפי דוגמת משרד התקשורת) | **403 Cloudflare** גם עם UA דפדפן [נבדק ✓ — חסום] |
| `dira.moch.gov.il` (הגרלות דירה בהנחה — האתר הרשמי) | 301 redirect, כפוף לאותה הגנת Cloudflare למעשה |
| דאטהסטים של רמ"י ב-data.gov.il (`the_israel_lands_administration`) | 3 דאטהסטים בלבד: מודדים, מרחבי שירות, מלאי תכנוני למגורים — **המעודכן ביותר מ-2022**, לא מכרזים חיים [נבדק ✓ — קיים אך לא עדכני] |
| חיפוש דאטהסטים "מכרזי מקרקעין" ב-data.gov.il | 0 תוצאות [נבדק ✓ — לא קיים] |
| `rmiclick.co.il` | שירות SaaS בתשלום של צד שלישי לעדכוני מכרזי רמ"י — לא מקור ראשוני, [דורש אימות אם רלוונטי בכלל] |

**מסקנה:** אין ל-רמ"י API/RSS ציבורי חינמי למכרזי מקרקעין/דיור. אפשרות עתידית: headless browser (Playwright) מול `land.gov.il/Land_Tenders/Pages/Tenders.aspx` — אבל זה כנראה גם מאחורי Cloudflare, ודורש תחזוקה גבוהה ביחס לתועלת. **לא מומלץ ל-MVP.**

### 2. משרד הבינוי והשיכון — משכנתא קהילתית, לוטריות דיור

| בדיקה | תוצאה |
|---|---|
| CKAN API: `data.gov.il/api/3/action/package_show?id=mechir-lamishtaken` | **200 OK, JSON תקין** [נבדק ✓ עובד] |
| Resource "מעקב אחר הגרלות דירה בהנחה" — datastore_search API | **200 OK, JSON מובנה**, 2,352 רשומות, resource עודכן `2026-08-16` [נבדק ✓ עובד ומעודכן] |
| שדות שימושיים בדאטה | `LamasName` (עיר), `Neighborhood`, `LotteryStatusValue` (סטטוס: "פורסמו תוצאות" וכו'), `LotteryExecutionDate`, `LotteryHousingUnits`, `PriceForMeter`, `Eligibility`, `MarketingMethodDesc` |
| הורדת קובץ CSV ישיר (`aws-e.data.gov.il/.../download/*.csv`) | **403 CloudFront** גם עם headers — **ה-API הרשמי (`datastore_search`) הוא הדרך הנכונה, לא ה-CSV הישיר** [נבדק ✓ — CSV חסום, API עובד] |
| עמוד RSS ייעודי למשרד הבינוי | 403 Cloudflare, כמו gov.il הראשי |

**מסקנה: זה המקור הכי חזק שמצאתי.** API JSON חינמי, יציב, ללא אימות, מתעדכן בפועל (עדכון תוך השבוע האחרון), ומכיל בדיוק את זוית "משכנתא קהילתית/לוטריות דיור" עם פילוח לפי עיר — קל לסנן לערים עם ריכוז יוצאי אתיופיה (LamasName = נתניה/אשדוד/לוד/באר שבע/קריית גת/ראשל"צ) ולהפוך רשומה חדשה ל"מכרז חדש נפתח ב-X" אוטומטית, בלי LLM אפילו לניסוח הבסיסי.

### 3. עיריות עם ריכוז אוכלוסיית יוצאי אתיופיה

| עירייה | סטטוס אתר (curl) | RSS שנמצא |
|---|---|---|
| לוד (lod.muni.il) | **302 → abuse.spd.co.il** (עמוד השעיית ספק דומיינים) [נבדק ✓ — לא פעיל כרגע] | — |
| נתניה (netanya.muni.il) | 200, אך redirect פנימי ל-`abuse.spd.co.il` גם כן בבדיקת follow [נבדק ✓ — בעייתי] | לא נמצא autodiscovery ב-HTML |
| אשדוד | 302 (רגיל, ככל הנראה http→https) | לא נבדק לעומק |
| קריית גת (k-gat.muni.il) | **000 — timeout/כשל DNS** [נבדק ✓ — לא זמין] | — |
| באר שבע | 302 (רגיל) | לא נבדק לעומק |
| ראשון לציון | 302 (רגיל) | לא נבדק לעומק |

**מסקנה:** אתרי העיריות בנויים על CMS ישן (כנראה "בר טכנולוגיות"/דומה) ללא RSS feed נגיש, וחלקם כרגע במצב לא תקין (abuse page / timeout) — לא אמין לתלות ישירה. **לא מומלץ ל-MVP**, אפשר לחזור ולבדוק שוב בעוד כמה שבועות אם האתרים יתייצבו, או לכסות עיריות דרך שאילתת Google News ממוקדת עיר (ראה סעיף 5).

### 5. Google News RSS (פתרון גנרי)

| בדיקה | תוצאה |
|---|---|
| `news.google.com/rss/search?q=יוצאי+אתיופיה+דיור&hl=iw&gl=IL&ceid=IL:iw` | **200, RSS 2.0 תקין** [נבדק ✓ עובד היטב] — 50+ כתבות רלוונטיות ואיכותיות מ-Globes, TheMarker, Calcalist, אתרי עיריות, לאורך שנים |

**יתרונות:** אפס תחזוקה לכל אתר בנפרד, מכסה את כל המקורות (כולל עיריות, גופי ממשל, תקשורת) דרך שכבה אחת, חינמי לגמרי, אין הגבלת quota ידועה לשימוש סביר. אפשר לבנות כמה שאילתות קבועות: `יוצאי אתיופיה דיור`, `יוצאי אתיופיה משכנתא`, `התחדשות עירונית לוד OR נתניה OR אשדוד`, `מכרז דיור קריית גת OR באר שבע`.
**חסרונות:** תוצאות לא סינכרוניות עם רגע הפרסום (יש דיליי), איכות/דיוק תלויים בניסוח השאילתה, וצריך דה-דופ מול Google News redirect URLs (ה-links הם קישורי הפניה של גוגל, לא ישירים למקור — נדרש resolve).

## פערים לבדיקה חוזרת (לפני build)

1. לוודא שוב חיבור ל-lod.muni.il ו-k-gat.muni.il בעוד כמה שבועות — ייתכן שהתקלה זמנית.
2. לאתר URL תקין ל-RSS של ynet (הניסיון בסבב זה נכשל — 404), או לוותר עליו לטובת Google News.
3. לבדוק Rate limit/ToS בפועל של Google News RSS לשימוש אוטומטי יומי (אין quota רשמי מתועד, אך שימוש אגרסיבי מדי עלול להיחסם).
4. לבחון scraping עם headless browser (Playwright, שכבר קיים ב-stack ל-QA) מול `land.gov.il` כפתרון עתידי לרמ"י — לא ל-MVP.
