# Tedros — Brand Decision Doc

**Owner**: Tedros Designer
**Status**: Phase 2, locked baseline 2026-04-27. Reviewable each phase gate.

> זהות מותג שמכבדת מורשת, מדברת לדור שני, ופועלת — לא מקשטת.

## 1. Brand essence

### Motto (HE / EN / AM)

|     |                                                       |
| --- | ----------------------------------------------------- |
| HE  | **טדרוס — מהמקום שלך, אל המקום שלך.**                 |
| EN  | **Tedros — From where you are, to where you belong.** |
| AM  | **ቴድሮስ — ካለህበት ወደ መልክህ።**                             |

### Personality

- **אקטיבית, לא נוסטלגית.** הכלי הזה גורם למשהו לקרות (לחתום, לדרוש, לפנות) — לא רק לזכור.
- **מכבדת, לא רגשנית.** מתייחסת לקהילה כמבוגרת. לא תמונות סטוק של "איש מבוגר עם מקל" וטקסטים מפוייטים.
- **חמה, לא חברית-בכוח.** טון "אחי/אחות" קיים בעברית, אבל לא חוצה לכותרות — שם שומרים על מקצועיות.
- **דו־כיוונית בלי תירוצים.** RTL הוא ברירת המחדל. אין layout שמרגיש "עברית מתורגמת".

### Values (ranked)

1. **כבוד מורשת.** הצבעים, הטיפוגרפיה, השפה — מתייחסים לבית ישראל, לסיגד, לגעז, ולא לעטיפה אקזוטית.
2. **שוויון פעולה.** כל מה שיהודי ותיק יכול לעשות באתר ממשלתי, גם בן הקהילה יכול — באמהרית, ללא מתווך.
3. **אמת מצוטטת.** כל מספר וטענה קשורים למקור (gov.il, CBS, רמ"י). E-E-A-T תהיה התחרות שלנו מול Yad2/Kol-Zchut.
4. **גישות AA+ כברירת מחדל.** אין דף שעובר QA בלי axe נקי.
5. **קצב.** העדפה ל-MVP פעיל בשבוע, על פני "perfect ב־3 חודשים".

### Anti-patterns (do NOT do)

- ❌ פלטה בצבעי דגל אתיופיה ב-100% רוויה כצבעים פרימריים — זה דגל, לא מותג.
- ❌ תמונות סטוק "אפרו" של חיוכים על רקע שדה.
- ❌ פונט דקורטיבי שמדמה "אמהרית קדומה" לכותרות עברית.
- ❌ אנימציות של "כיסוי השריון" / "סיפור ביציאת מצרים" — זה פטרוני.
- ❌ שימוש ב-Comic Sans, Aharoni או Frank Ruehl Libre כברירת מחדל. Heebo בלבד לעברית.

## 2. Logo direction (3 כיוונים מוצעים — ה-Engineer יבחר עם המשתמש)

עוד אין לוגו רשמי. שלוש הצעות עקרוניות, כולן wordmark-first (לא תלוי בסמל גרפי בנעלילים קטנים):

### Direction A — "Wordmark נקי + נקודה"

טדרוס באות עברית של Heebo Bold, עם נקודה עגולה (#FF6B35 — Tedros Earth) מעל ה־ת'. ב־EN: `Tedros` באותו הסגנון (Inter Tight Bold), נקודה מעל ה־i. **חוזק**: מינימליסטי, עובד מ־24px עד billboard. **חסרון**: אין סמל מובחן ל-favicon/ אפליקציה.

### Direction B — "Mark של אות"

לוגו = הסמל הא־סימטרי של האות **ת** (HE) או **T** (EN), עם פתח שמרמז על דלת בית. צבע: gradient אדמה→ירוק. **חוזק**: מתאים ל־favicon ו־app icon. **חסרון**: שלוש שפות = שלושה סמלים? אפשרי לעשות ל־am כ־ቴ.

### Direction C — "Path / מעברים"

שתי קווי קלות (אופקיים) שנפגשים בנקודה — מסמלים מעבר/דרך/ירידה לארץ → קהילה. מתחתם wordmark. **חוזק**: מספר סיפור בלי להיות פיגוראטיבי. **חסרון**: דורש ביצוע מדויק כדי לא להיראות גנרי.

**המלצת Designer**: להתחיל עם **A** ב־Phase 2 (זה הכי בטוח ומהיר), ולעבור ל־**B** או **C** אחרי ש־MVP נדל"ן באוויר ויש פידבק קהילתי. ב-tokens יש placeholder `--logo-mark-color` שמאפשר החלפה.

## 4. Typography

### Stacks

| Script       | Family                                            | Fallback                            |
| ------------ | ------------------------------------------------- | ----------------------------------- |
| Hebrew (HE)  | **Heebo** 400/500/600/700                         | Assistant, ui-sans-serif, system-ui |
| Latin (EN)   | **Inter** 400/500/600/700 + Inter Tight (display) | ui-sans-serif, -apple-system        |
| Amharic (AM) | **Noto Sans Ethiopic** 400/500/700                | Nyala, Abyssinica SIL, system-ui    |
| Mono         | **JetBrains Mono** 400/500                        | ui-monospace, Menlo                 |

### Loading strategy

- Self-host via `@fontsource-variable` packages (Heebo Variable, Inter Variable, Noto Sans Ethiopic Variable).
- `<link rel="preload" as="font" type="font/woff2" crossOrigin>` only for the active locale's primary face (Heebo for HE, Inter for EN, Noto for AM) — keeps LCP under ADR-005's 1.5s budget.
- `font-display: swap` on all secondary weights.

### Type scale (modular, ratio 1.25, base 16px)

| Token       | px  | rem    | Use             |
| ----------- | --- | ------ | --------------- |
| `text-2xs`  | 11  | 0.6875 | metadata        |
| `text-xs`   | 12  | 0.75   | caption, helper |
| `text-sm`   | 14  | 0.875  | body small      |
| `text-base` | 16  | 1.0    | body            |
| `text-lg`   | 18  | 1.125  | lead            |
| `text-xl`   | 20  | 1.25   | h5              |
| `text-2xl`  | 24  | 1.5    | h4              |
| `text-3xl`  | 30  | 1.875  | h3              |
| `text-4xl`  | 36  | 2.25   | h2              |
| `text-5xl`  | 48  | 3.0    | h1              |
| `text-6xl`  | 60  | 3.75   | hero            |

### Line-height

- Heading: 1.15
- Body: 1.6 (HE/AM benefit from extra leading vs. EN's 1.5)
- Body-tight: 1.4 (lists, tables)

### RTL & i18n notes

- HE prefers slightly **larger** weight for headings (Heebo 700 reads thinner than Inter 700).
- AM Ge'ez glyphs are taller — bump line-height to 1.7 in `[lang=am]`.
- Numbers stay LTR even inside RTL context — wrap with `<bdi>` in components like price/phone.

## 5. Spacing, radii, shadows, motion

### Spacing scale (rem)

`0, 0.25, 0.5, 0.75, 1, 1.5, 2, 3, 4, 6, 8, 12, 16, 24` (4/8/12/16/24/32/48/64/96/128/192/256/384px)

### Radii

- `radius-xs` 4px (chip, small badge)
- `radius-sm` 6px (button default)
- `radius-md` 10px (input, card-inner)
- `radius-lg` 14px (card, dialog)
- `radius-xl` 20px (hero card, sheet)
- `radius-full` 9999

### Shadows (subtle, no neumorphism)

- `shadow-xs` `0 1px 2px hsl(30 10% 10% / 0.05)`
- `shadow-sm` `0 1px 3px hsl(30 10% 10% / 0.08), 0 1px 2px hsl(30 10% 10% / 0.04)`
- `shadow-md` `0 4px 12px hsl(30 10% 10% / 0.08), 0 2px 4px hsl(30 10% 10% / 0.04)`
- `shadow-lg` `0 12px 32px hsl(30 10% 10% / 0.12), 0 4px 8px hsl(30 10% 10% / 0.04)`

### Motion

- `motion-fast` 120ms ease-out (hover, focus)
- `motion-base` 200ms cubic-bezier(.2,.8,.2,1) (open/close, fade)
- `motion-slow` 320ms cubic-bezier(.2,.8,.2,1) (drawer, sheet)
- `prefers-reduced-motion: reduce` → all transitions become 1ms.

### Z-index

`base 0`, `dropdown 1000`, `sticky 1100`, `fixed 1200`, `modal-backdrop 1300`, `modal 1310`, `popover 1400`, `tooltip 1500`, `toast 1600`.

## 6. RTL & directionality

- `dir` is set on `<html>` from the loader (he, am → rtl; en → ltr). Note: although Amharic uses Ge'ez script that reads LTR, the original brief specified RTL — current i18n config keeps EN as LTR and HE as RTL; AM is set to LTR per the actual Ge'ez script. **Decision: AM stays LTR**, with a `useGeezReadingOrder` opt-in for ceremonial/liturgical pages later.
- Components use **logical properties only** (`ms-`, `me-`, `ps-`, `pe-`, `start-`, `end-`, `text-start`, `text-end`). No `ml-`/`mr-` in components.
- Icons that point: chevron-end, arrow-end — flip automatically via `[dir="rtl"] .icon-flip { transform: scaleX(-1); }`.
- Numbers, codes, URLs always wrapped with `<bdi>` to prevent BiDi mirroring inside RTL containers.

## 7. Accessibility (AA+ baseline)

- Focus ring: 2px solid `--ring`, `outline-offset: 2px`. Visible on every interactive element. Never removed.
- Hit target: ≥ 44×44 CSS px on touch.
- Color is never the sole signal (errors carry icon + text; status badges carry label).
- Form errors are `aria-describedby` linked, not just colored.
- Skip link to `#main-content` in every page template.
- Headings strictly hierarchical (h1 once per page, no skipping levels).
- Motion respects `prefers-reduced-motion`.
- All components: keyboard nav verified (Tab, Shift+Tab, Esc, Enter, Space, Arrow keys for menus/tabs).
- Screen-reader: tested with VoiceOver (HE) + NVDA (EN) before any handoff.
